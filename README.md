### ✨ Highlights

A sleek, high-performance personal developer portfolio built with a dark obsidian glassmorphic aesthetic (`#090D16`) and cyan neon accents (`#00F0FF`).

- **🌌 3D Interactive Graphics:** Ambient 3D floating nodes and particle network powered by Three.js & React Three Fiber.
- **⚡ Instant Project Search:** Real-time fuzzy filtering across 10+ full-stack, AI/ML, and mobile projects.
- **🔍 Deep Architecture Modals:** Qualification checklists, technical specifications, and repository source links for every project.
- **📄 In-App Resume Viewer:** Dedicated modal for quick PDF viewing and instant download.
- **📱 Fully Responsive:** Adaptive layouts with custom scrollspy navigation and glassmorphic micro-interactions.
